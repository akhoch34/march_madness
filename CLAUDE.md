## Project Overview

March Madness prediction project for Kaggle competitions (men's and women's NCAA tournaments). The workflow generates probabilistic win predictions for all possible matchups, submitted as a combined M+W CSV file.

**Scoring metric**: Brier score = mean((pred - actual)²). Lower is better. Random = 0.25.

## Data Layout

- Data files: `data/<year>/` — flat structure (no MDataFiles/ subdirectory after 2023)
- Format: `{M|W}Teams.csv`, `{M|W}RegularSeasonCompactResults.csv`, etc.
- `data/2026/` contains cumulative data through 2025 (use for historical scoring)
- **Gotcha**: Women's data has no Massey Ordinals. Women's Teams.csv lacks `FirstD1Season`/`LastD1Season` — cross-reference with men's teams by name.
- **Season skip**: 2020 excluded everywhere (COVID — no tournament).
- 2022 data: flat under `data/2022/MDataFiles_Stage1/` and `MDataFiles_Stage2/`
- 2023 data: under `data/2023/MDataFiles/` and `WDataFiles/`
- 2024+ data: flat in `data/<year>/`

## Running Notebooks

**Each year, update `CURRENT_SEASON` at the top of the notebook.**

1. **Primary pipeline**: `notebooks/elo_enhanced.ipynb` — most reliable, full ELO+ML
2. **Ensemble approach**: `notebooks/xgb_ensemble.ipynb` — historically competitive
3. **Baseline**: `notebooks/baseline_massey.ipynb` — fast sanity check
4. **Scoring**: `notebooks/score_historical.ipynb` — evaluate all historical submissions in `output/`
5. **Bracket viz**: `notebooks/generate_bracket.ipynb` — bracket PNG/HTML for any season

Outputs go to `output/`. Historical artifacts live under `output/{year}/{method}/submissions/` and `output/{year}/{method}/brackets/`. Runtime feature caches live under `output/{year}/features/`.

**Backtesting:** Set `CURRENT_SEASON` to a past year and `DATA_DIR = "../data/2026"` (cumulative). The 2026 dataset has all results through 2025 and is the correct source for historical analysis.

**Women's data fallback:** `xgb_ensemble.ipynb` and `baseline_massey.ipynb` wrap women's data loading in try/except. If women's files are missing (e.g., in year-specific dirs), they print a warning and skip women's predictions. Use `DATA_DIR = "../data/2026"` for complete M+W output.

## Submission Format

```
ID,Pred
2026_1101_1102,0.6234
...
```
- `ID` = `{Season}_{lower_TeamID}_{higher_TeamID}`
- `Pred` = P(lower-ID team wins)
- Must include ALL possible team matchups for both M and W
- Clip predictions to [0.025, 0.975] to avoid extreme log loss

## Prediction Methods

**Notebook-backed** (in `src/approaches/notebook_models.py`):

| Method | Description |
|--------|-------------|
| `seed_spline_only` | `UnivariateSpline` on (SeedDiff, result). Zero ML. |
| `baseline_massey` | XGBoost on win%, seed diff, Massey rank. 30% XGB + 70% spline. |
| `massey_direct` | Logistic regression on per-system Massey rank diffs. 25% LR + 75% spline. Women's fallback: spline only. |
| `massey_blend` | No training — average normalized ranks across 6 Massey systems. 40% Massey + 60% spline. Women's fallback: spline only. |
| `xgb_ensemble` | 5-model ensemble (HistGBM/RF/LR/SVC/XGB). Advanced shooting/efficiency stats. 30% ensemble + 70% spline. |
| `xgb_ensemble_v2` | Like `xgb_ensemble` + conference tourney signals + per-system Massey columns. 30% ensemble + 70% spline (20% for W). |
| `recency_xgb` | Same as `baseline_massey` but rows weighted by `0.75^(season_gap)`. 30% weighted XGB + 70% spline. |
| `poisson_margin` | Expected margin `(OffEff_t1 − DefEff_t2) − (OffEff_t2 − DefEff_t1)`, logistic fit. 35% margin LR + 65% spline. |
| `seed_matchup_calibration` | Empirical win-rate lookup by `(seed_lo, seed_hi)` pair blended with `xgb_ensemble_v2`. 35% historical rate + 65% xgb_v2. |
| `meta_ensemble` | Stacked meta-LR on OOF preds of `xgb_ensemble_v2` + `massey_direct`. Slow (~5+ min). 50% meta-LR + 50% spline. |

**Predictor-backed** (via `src/data_classes/processing/Predictor.py`; poor Brier ~0.30):
- `elo` — pure ELO rating prediction
- `elo_enhanced` — ELO + XGBoost residual correction

**Default methods for `eval_framework.py`** (9 fast notebook methods, excludes `meta_ensemble`/`elo`/`elo_enhanced`).
**Default methods for `generate_historical_artifacts.py`**: `elo`, `elo_enhanced`, `baseline_massey`, `xgb_ensemble`.

## Key Conventions

- All `src/data_classes/` classes accept `gender="M"` or `gender="W"`
- Output directory: `output/` (relative to where notebook runs)
- XGBoost is used throughout and IS listed in pyproject.toml
- BracketGenerator no longer uses PIL — slot coordinates are inlined in `BracketGenerator.py` as `SLOTS`
- `visualize_bracket()` and `visualize_historical_bracket()` delegate to `src/visualization/bracket_viz.py`
- `bracket_viz.py` renders via matplotlib with proper region layout, round headers, connector lines, and seed badges
- `BracketGenerator.get_bracket_layout()` returns structured dict (region → games) used by the new renderer
- Team logos: run `poetry run python utils/download_logos.py` to fetch ESPN logos → `data/logos/{M|W}/{team_id}.png`; pass `show_logos=True` to `visualize_bracket()` to use them
