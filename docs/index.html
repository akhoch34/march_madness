Prediction Methods

modeh7

2025 Kaggle 1st-place solution. LOSO XGBoost on point differential with spline calibration. Trains on combined M+W data.

upset_aware_ensemble

xgb_ensemble_v2 extended with upset-specific features: HistMatchupRate_Diff, DefFirstRatio, RecentMomentum, MasseyVsSeedGap. 70% ML / 30% spline for men's.

xgb_ensemble_v2

5-model ensemble (HistGBM, RF, LR, SVC, XGBoost) with conference tourney signals and per-system Massey columns.

seed_matchup_calibration

Empirical win-rate lookup by (seed_lo, seed_hi) pair blended with xgb_ensemble_v2. Falls back to spline for rare matchups.

recency_xgb

Baseline Massey features with training rows weighted by 0.75^(season_gap) — recent seasons count more.

poisson_margin

Expected margin from offensive/defensive efficiency, fit with logistic regression on historical (margin, result) pairs.

massey_direct

Logistic regression on per-system Massey rank differences (POM, SAG, DOK, MOR, MAS, RPI).

seed_spline_only

UnivariateSpline fitted purely on seed difference. Zero ML — useful as a sanity-check baseline.
